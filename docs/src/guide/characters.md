# Character Gallery

Every built-in character `cl-cowsay` ships, rendered with `cl-cowsay -c NAME
"Hi!"` -- default eyes (`oo`), no tongue, speech-bubble mode. Run
`cl-cowsay -l` to print this same list of names from the command line, or
`cl-cowsay -r "..."` to let it pick one for you.

All 29 are original ASCII art written for this project; none is copied from,
or a rendering of, upstream `cowsay`'s `.cow` files.

## cow

The default. Ears, a two-character eyes slot, a body that can carry a
tongue, and two hoof legs.
